# Chess Me

Chess Me 是一个面向个人棋力提升的国际象棋复盘与训练工具。它把 PGN/FEN 复盘、棋盘试走、Stockfish 分析、猜下一手训练和整盘自动标注放在一个轻量 Web 应用里，目标是帮助你把每盘棋转化成可重复训练的素材。

## 项目目标

本项目不是只做“看棋谱”的工具，而是作为你的国际象棋训练助手：

- 用 **猜下一手** 训练候选着法、计算和局面判断。
- 用 **Stockfish 对比** 找出实战手和引擎首选之间的差异。
- 用 **一键全局分析** 快速定位疑问手、失误、败着和局势突变点。
- 用 **笔记和变化线** 记录自己的思考过程，沉淀成可复盘的训练材料。

## 当前分支功能

当前分支：`feat/game-import-filtering`

### 1. PGN / FEN 复盘

- 粘贴 PGN 棋谱或 FEN 局面。
- 支持导入 PGN 文件。
- 批量导入 PGN 会形成临时棋库：自动识别 Lichess / Chess.com / 手动来源，按日期、对手、结果、执棋颜色、开局和重要标记筛选，并支持按日期、对手、结果、开局、来源、重要程度排序。
- 批量棋库与复盘历史互通：相同 PGN 自动去重，历史里的重要报告会在棋库中继承星标，棋库内切换重要标记也会同步到对应历史报告。
- 支持逐步前进/后退浏览棋局。
- 支持复制当前 FEN。
- 支持导出带个人笔记和保存变化线的 PGN。

### 2. 交互棋盘与变化图

- 点击棋子或拖拽走棋。
- 高亮上一手和合法目标格。
- 可在任意局面试走变化线。
- 可保存变化线，导出 PGN 时写入分支。
- 支持悔一步、恢复原局面。

### 3. Stockfish 局面分析

- 内置 Stockfish 18 Web Worker。
- 默认优先使用 WASM，失败或超时时自动切换 ASM 兼容模式。
- 支持当前局面分析：
  - 评分
  - 深度
  - 最佳手
  - 主线 PV
- 支持三种评分视角：
  - 白方
  - 执棋方
  - 当前棋盘方向
- 一键全局分析运行时会显示 **取消分析** 按钮；点击后会立即向 Worker 发送 stop，清理当前 pending 请求和错误状态，保留取消前已经完成的分析结果，并把按钮恢复为可再次启动的 **分析整盘**。

### 4. 猜下一手训练模式

新增 **猜下一手训练** 面板。

训练流程：

1. 点击 **开始训练**。
2. 当前局面的棋谱下一手会被隐藏，走法列表显示 `??`。
3. 你先在棋盘上走出自己的判断。
4. 系统自动对比：
   - 你的猜测
   - 实战手
   - Stockfish 首选
5. 如果你猜对实战手，电脑会按照 PGN 棋谱自动走出对方下一手，并把棋盘推进到你的下一回合，形成连续人机对战训练。
6. 系统自动记录：
   - 猜对次数
   - 猜错次数
   - 正确率
7. 点击 **下一题** 可跳过当前回合进入后续局面继续训练。

这个模式的训练目的：

- 逼自己先思考，而不是直接看实战答案。
- 对比“人类实战选择”和“引擎首选”。
- 发现自己常漏掉的战术、战略计划和防守资源。

### 5. 一键全局分析

新增 **一键全局分析** 面板。

功能：

- 自动逐步分析整盘棋。
- 支持 `快速` / `标准` / `深度` 三档一键预设，对应不同 Stockfish 深度、超时和 MultiPV 数量。
- 支持中途取消整盘分析，取消后停止 Worker 当前请求并保留取消前已有结果。
- 对相同 PGN + 分析预设 + 深度 + MultiPV + 引擎模式使用内存缓存；可直接命中缓存，也可点击刷新强制重跑。
- 支持 `全部` / `关键时刻` 筛选，只聚焦疑问手、失误、败着、局势突变点和大幅评价波动。
- 关键时刻 helper 会给出严重度、训练价值和原因摘要；筛选结果保持原分析行引用，不改写整盘分析数据，复盘报告与训练入口可复用同一批结果。
- MultiPV 候选主线会随每步分析结果展示，包含候选排序、SAN 主线、UCI 主线和评分；如果引擎未返回 MultiPV 数据，则降级显示既有 Stockfish 首选/主线。
- 为每一步打标签：
  - `好棋`
  - `疑问手`
  - `失误`
  - `败着`
- 显示每步的估算损失 cp。
- 显示每步对应局面的 Stockfish 首选。
- 自动标出 **局势突变点**。
- 点击结果可跳转到对应棋步。

标签逻辑基于走棋方视角的局面损失：

| 标签 | 大致含义 |
| --- | --- |
| 好棋 | 损失很小，基本维持局势 |
| 疑问手 | 有一定损失，值得复盘 |
| 失误 | 明显损失，需要找原因 |
| 败着 | 重大损失，通常是关键错误 |

### 6. 训练闭环 / 错题本

当前分支新增 **训练闭环** 能力，基于错题本继续往可执行训练计划推进。

功能：

- 猜下一手错误会自动生成错题卡，手动也可以把当前局面加入错题本。
- 错题卡记录尝试次数、完成次数、训练标签、复习阶段和下次到期时间。
- 支持 1 天、3 天、7 天、14 天的间隔复习节奏。
- 自动生成每日 10 题训练计划：优先今日到期题，其次补充弱标签/低完成率题目。
- 支持按训练标签统计完成率，帮助识别需要优先强化的主题。
- 复习时可标记“完成复习”或“仍需复习”，系统自动调整下次到期时间。

### 7. 候选着法训练

当前分支新增 **候选着法训练**，把“先列候选、再做选择”嵌入猜下一手流程。

功能：

- 在猜下一手前，可输入 2-3 个候选着法，每个候选支持写一句理由。
- 提交棋盘最终走法后，系统自动对比候选清单、实战手和 Stockfish 首选。
- 如果当前局面已有 Stockfish MultiPV 数据，会直接复用已有分析缓存，把每个用户候选着法与 MultiPV 候选线对比：显示是否命中、命中排名、与最佳线的评价差以及关键变例。
- 训练反馈不只给分数，还会解释 `最佳着法`、`可接受着法`、`风险着法`、`漏算着法`，帮助复盘为什么该候选可选或危险。
- 没有 MultiPV 数据时会降级为候选着、实战答案和 Stockfish 首选的基础对比，不会额外启动不必要分析。
- 记录“实战答案在候选里但最终没选中”的情况，用于定位排序/选择能力问题。
- 统计候选答案覆盖率、平均排序得分、有效训练次数和有答案未选次数。
- 本地保留最近 20 次候选训练摘要，方便连续训练时快速回看。

### 8. 开局提升

当前分支新增 **开局提升**，把原有开局识别扩展为可训练的开局复盘模块。

功能：

- 自动识别当前 PGN 的常下开局，并展示 ECO、开局名和当前状态。
- 记录实战在哪一个 ply 脱离内置开局库，并显示实战手与推荐库线。
- 根据对局着法生成开局复习卡片提示，用于后续加入错题本或专项复习。
- 统计常见开局、脱谱次数和脱谱率，帮助定位最需要优先复习的开局。
- 当前支持内置开局库；自定义开局库与跨多盘统计保留为后续扩展。

### 9. 历史复盘报告

当前分支新增 **历史复盘报告**，把单盘复盘结论沉淀成本地可检索的长期训练档案。

功能：

- 在整盘复盘报告生成后，可点击 **保存到历史**，把 PGN、对局信息、摘要、关键时刻和训练建议保存到本地浏览器。
- 历史报告使用版本化 localStorage 存储；相同 PGN 会去重，避免重复点击造成多份相同记录。
- 支持按赛事、棋手、结果、报告摘要、训练建议和关键着法搜索。
- 支持按结果筛选、只看重要报告、标记/取消重要、重新打开 PGN 以及删除历史记录。
- 自动统计历史报告数量、重要报告数量、关键时刻总数和最常见训练主题，并把长期沉淀摘要接入个人棋力画像。

## 使用场景

1. 从 lichess、Chess.com 或其他平台导出 PGN。
2. 批量导入多个 PGN 文件，按来源、日期、对手、结果、执棋颜色、开局或重要标记筛出本次要复盘的棋局。
3. 粘贴或载入到 Chess Me。
4. 先不开引擎，自己逐步复盘。
5. 开启猜下一手训练，在关键局面先自己走。
6. 开启 Stockfish 分析，对比实战手和引擎首选。
7. 用一键全局分析快速找出全局错误分布。
8. 生成整盘复盘报告，并把高价值报告保存到历史。
9. 定期回看历史复盘报告和个人棋力画像，确认训练主题是否收敛。

### 针对性训练

- 如果经常出现 `败着`：重点训练战术、王安全和一步漏算。
- 如果经常出现 `失误`：重点训练候选着法比较和局面评估。
- 如果很多 `疑问手`：重点训练计划选择、子力协调和残局转换。
- 如果猜下一手正确率低：先降低速度，强制写出 2-3 个候选着法再走。

## 推荐训练流程

每盘棋建议按这个顺序使用：

1. **无引擎自我复盘**：先写下自己认为的关键点。
2. **猜下一手训练**：从第一个不确定局面开始做题。
3. **一键全局分析**：找出实际最大失分点。
4. **重点复盘突变点**：只深挖 2-4 个关键错误。
5. **记录训练结论**：写成可执行的下一步训练任务。
6. **加入错题本**：未来通过间隔复习巩固。

## 设计原则

- 先思考，后看答案。
- 少看整盘平均评价，多看关键转折。
- 不只问“哪步错了”，还要问“为什么我会这样想”。
- 每次复盘只沉淀少量高价值训练点。
- 工具服务于棋力提升，而不是替代思考。
